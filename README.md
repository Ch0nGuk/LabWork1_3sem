# AVL-дерево

Учебный проект на C++, реализующий бинарное AVL-дерево для хранения пар «ключ — значение» и поиска данных по ключу.

## Что реализовано

- Вставка, поиск и удаление элементов.
- Итератор с передаваемой стратегией обхода и шестью готовыми порядками.
- Операции `map`, `where`, `reduce` и извлечение поддерева.
- Консольный интерфейс для работы с деревом чисел и деревом студентов. У студента хранятся фамилия, имя, номер группы и телефон; ключом служит ID.
- Тесты основных операций и нагрузочные тесты на наборах от 10 тысяч до 2 миллионов элементов.

При запуске создаются два демонстрационных дерева: 1023 числа и 1023 студента.

## Балансировка

Каждый узел хранит высоту своего поддерева. После вставки или удаления высоты обновляются на пути к корню. Если высоты левого и правого поддеревьев различаются более чем на один уровень, выполняется одинарный или двойной поворот. Это сохраняет логарифмическую высоту дерева.

## Сборка и запуск

Требуются CMake 3.16 или новее и компилятор с поддержкой C++20.

```bash
cmake -S . -B build
cmake --build build
./build/lab_app
```

Пункт 11 в меню запускает тесты. Исходные замеры и график среднего времени по 30 запускам находятся в каталоге `benchmarks`.
